YouTube Analytics Pipeline

A daily pipeline that snapshots YouTube channel analytics into BigQuery for historical trend analysis.

Use case Personal analytics for the developer's own YouTube channel.
Storage BigQuery tables in the developer's Google Cloud project.
Access Read-only YouTube Analytics API access.

What This App Does

YouTube Analytics Pipeline reads YouTube Analytics reports for a channel owned by the consenting Google account and writes daily snapshots to BigQuery. The dataset is used to analyze trends over time, including watch time, retention, subscriber changes, shares, and traffic source performance.

The app is a single-user automation tool. It is not a hosted analytics service, it does not provide accounts for other users, and it does not publish private YouTube Analytics data.

What This App Accesses

The app requests the OAuth scope https://www.googleapis.com/auth/yt-analytics.readonly. This scope allows the app to view YouTube Analytics reports for YouTube content owned by the consenting account.

The app uses this read-only scope to fetch analytics metrics such as estimated minutes watched, average view duration, average view percentage, subscribers gained, subscribers lost, shares, views, and traffic source breakdowns.

Who Can Use This

This app is intended for the developer's own YouTube channel. The OAuth grant is completed by the Google account that owns or manages that channel, and the resulting data is stored only in the developer's Google Cloud project.
