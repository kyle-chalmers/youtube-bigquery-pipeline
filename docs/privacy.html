Privacy Policy

This policy explains how YouTube Analytics Pipeline accesses, uses, stores, shares, retains, deletes, and protects Google user data.

Effective date: May 25, 2026
Last updated: May 25, 2026

1. What Google User Data the App Accesses

YouTube Analytics Pipeline requests the OAuth scope https://www.googleapis.com/auth/yt-analytics.readonly. This read-only scope allows the app to view YouTube Analytics reports for YouTube content owned by the consenting Google account.

The app accesses the following YouTube Analytics data:

  • Estimated minutes watched
  • Average view duration
  • Average view percentage
  • Subscribers gained and subscribers lost
  • Shares
  • Views by traffic source type
  • Watch time by traffic source type

The app does not request write access to YouTube, Gmail, Drive, Calendar, contacts, payments, or any unrelated Google account data.

2. How the Data Is Used

The data is used only to populate a BigQuery dataset owned by the same developer who grants OAuth access. The purpose is personal historical trend analysis for the developer's own YouTube channel.

The app uses the data to answer analytics questions such as which videos gained watch time, which traffic sources drove views, how retention changed over time, and how videos affected subscriber growth.

3. How the Data Is Stored

YouTube Analytics data is stored in BigQuery tables inside the developer's Google Cloud project. The app does not store private YouTube Analytics data outside Google Cloud.

Google Cloud encrypts BigQuery data at rest. OAuth client credentials and refresh tokens are stored in Google Secret Manager with IAM-restricted access. Credentials are not stored in source code.

4. How the Data Is Shared

Google user data accessed by this app is not shared, sold, transferred, rented, or disclosed to third parties.

Use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The app does not sell Google user data to third parties. The app does not use or transfer Google user data for targeted advertising, retargeting, personalized advertising, interest-based advertising, data brokering, credit determinations, lending purposes, or training generalized AI or machine learning models.

5. How Long the Data Is Retained

Analytics snapshots are retained in BigQuery while the pipeline remains active. The data is retained indefinitely by default so historical trend analysis remains possible.

The developer can delete the BigQuery tables or dataset at any time.

6. How the User Can Request Deletion

The user of this app is the developer who owns the YouTube channel and Google Cloud project. To delete data and revoke access:

  1. Delete the BigQuery tables or dataset that contain the YouTube Analytics snapshots.
  2. Revoke the app's OAuth grant at https://myaccount.google.com/permissions.
  3. Delete the OAuth refresh token from Google Secret Manager.

Deletion requests or questions can also be sent to contact@kclabs.ai.

7. Security Practices

The app uses OAuth 2.0 for user consent and read-only YouTube Analytics API access. OAuth credentials are stored in Google Secret Manager and accessed by the Cloud Function through Google Cloud IAM. The repository does not contain plaintext credentials, refresh tokens, API keys, or downloaded OAuth client secret files.

OAuth authorization is performed through Google's HTTPS authorization flow. Runtime access to stored secrets and BigQuery data is limited through Google Cloud IAM permissions.

8. Contact

Questions about this privacy policy or Google user data handling can be sent to contact@kclabs.ai.
