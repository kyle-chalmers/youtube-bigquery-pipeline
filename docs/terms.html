Purpose

YouTube Analytics Pipeline is a single-user automation tool that reads YouTube Analytics reports for the developer's own YouTube channel and stores daily snapshots in BigQuery for historical analysis.

Use of the App

The app is intended for use by the developer who owns or manages the connected YouTube channel and Google Cloud project. The app is provided as-is for that analytics workflow.

Google API Use

The app uses Google APIs only after OAuth consent is granted by the Google account that owns or manages the YouTube channel. Use of Google user data is described in the Privacy Policy.
